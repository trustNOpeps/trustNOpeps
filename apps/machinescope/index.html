03 / METHOD & GUIDE

Transparan sejak awal.

Deteksi memakai median dan median absolute deviation (MAD): skor = 0.67448975 × |x − median| / MAD. Nilai dengan skor di atas ambang ditandai. Ini analisis statistik, belum model machine learning terlatih atau diagnosis kerusakan.

Jika MAD = 0, setiap nilai yang berbeda dari median ditandai sebagai deviasi baseline konstan. Baseline seluruh data dapat terpengaruh perubahan rezim; gunakan 25% awal hanya jika periode itu mewakili kondisi normal. Tidak ada estimasi sisa umur mesin.

Mulai dengan data sendiri

  1. Siapkan CSV UTF-8 dengan header unik dan pemisah koma.
  2. Gunakan titik untuk desimal. Maksimal 5 MB / 50.000 baris.
  3. Pilih kanal numerik, baseline, dan ambang; tinjau anomali.
  4. Ekspor laporan JSON atau daftar anomali CSV.

Satuan dibaca dari nama kolom, tidak dikonversi. Nilai kosong/invalid dikecualikan dan dilaporkan. Verifikasi indikasi dengan konteks operasi mesin.
