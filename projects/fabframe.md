# FABFRAME — Parametric CAD

[Live app](https://trustnopeps.github.io/trustNOpeps/apps/fabframe/) · [Source](../apps/fabframe/)

Student and fabrication-planning tool: configurable hollow frames, orthographic views, nominal mass, cut schedules, indicative costs and JSON project storage. Exports SVG, DXF, CSV and FreeCAD macro for STEP/FCStd.

Validated JavaScript calculations and JSON roundtrip; default model produced 12 valid hollow solids and 1,415,680 mm³ in FreeCAD. STEP/FCStd export succeeded. GUI folder dialog and commercial CAD imports remain unverified. No load rating or production-tolerance certification.

Source: main/apps/fabframe. Publication: gh-pages/apps/fabframe. Export local projects as JSON from the old domain before importing on this new domain.
